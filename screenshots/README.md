# Скриншоти и скринкастови

Во оваа папка ставете ги (како што бара проектната задача):

1. **Скриншоти** од апликацијата (`.png` / `.jpg`) — на пр.:
   - `01_login.png` — екран за најава
   - `02_task_list.png` — листа на задачи (телефон)
   - `03_add_task.png` — додавање задача
   - `04_tablet.png` — приказ на таблет (две колони)
   - `05_settings_mk.png` — поставки на македонски
   - `06_settings_en.png` — поставки на англиски

2. **Скринкаст видеа** (`.mp4`) од користење на апликацијата — на пр.:
   - `screencast_login_and_crud.mp4`
   - `screencast_sync_firestore.mp4`

> Совет: На Android Studio емулаторот, копчето за снимање екран се наоѓа
> во лентата со алатки од десната страна (камера = скриншот, видео = скринкаст).
